# Project page data

The interactive figure on the project page uses `explorer.json`: the 2D positions of 600 CT-RATE validation scans and their reports in the report feature space, and the finding labels of each scan. The file contains no scan images, no report text and no scan identifiers.

The positions and labels are derived from [CT-RATE](https://huggingface.co/datasets/ibrahimhamamci/CT-RATE) (CC BY-NC-SA 4.0). The Apache License 2.0 of the code does not apply to this directory.
